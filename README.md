# v64otd.com Documents

This repository holds the public documents for [v64otd.com](https://v64otd.com). Files stored here are linked from the website so visitors can view them online or download them.

## Purpose

- Keep a single, public home for documents shared on v64otd.com
- Provide stable links for viewing and downloading
- Track changes to each document over time through version history

## Viewing and downloading

- **View:** Click a document name in the table above, or browse the files list. GitHub displays PDFs in the browser.
- **Download:** Open the file and click the **Download** button (or **Download raw file**) at the top right of the preview.
- **Direct link for the website:** Use the raw file URL so the link downloads or opens the file directly:

  `https://raw.githubusercontent.com/<owner>/<repository>/main/<file-name>.pdf`

  Replace `<owner>`, `<repository>`, and `<file-name>` with the actual values. Spaces in file names become `%20` in links.

## Adding a document

1. Click **Add file**, then **Upload files**.
2. Drag in the document. Use short file names without spaces where possible (for example, `data-privacy-act.pdf`).
3. Add a row for it in the **Documents** table above.
4. Click **Commit changes**.

To replace a document with a newer version, upload a file with the same name. GitHub keeps the earlier versions in the file's history.

## Usage

Documents are provided for public viewing and download. Unless a document states otherwise, please credit v64otd.com when sharing or quoting it.
